# PartyBox content packs

Public workshop for game content built from open data: reproducible scripts, JSON packs, JSON Schemas and checks. Each pack lives in jobs/<ID>-<slug>/.

- RUN-ALL.md: the message that starts an agent working the queue.
- RULES.md: binding rules for every job.
- JOBS.md: the queue.
- CLAIMS.md: who is working on what.

Licence: MIT for scripts. Data keeps its source licence; see each job's SOURCES.md.
