## Original test media and knowledge limits

The portrait tests create30 original deterministic image patterns in temporary
directories. They are engineering fixtures generated by this project, released
CC0 for that purpose. They are not depictions of any sample person.
Portrait-tool attribution metadata has provenanceStatus=caller-supplied; accepting
a Commons URL/license string is not license verification.
No mirror portrait with unverified original rights is committed.

Date-domain and status-selection rules are implemented from job requirements;
no biography or alive/dead answer has been invented from knowledge. Source
API details, current status, licensed portraits and independent fact lines remain
unverified, as listed in NEXT under Re-verify when web works.
